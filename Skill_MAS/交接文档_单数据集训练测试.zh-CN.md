# Skill-MAS 单数据集交接说明

本仓库是可移植的 Skill-MAS 单数据集运行版本。每次运行选择一个 native adapter，不包含混合数据集入口，也不要求使用原开发机上的目录结构。

## 快速启动

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# 编辑 .env，填写 API 和外部 benchmark 路径
source .env
```

训练入口位于 `run_single_training.sh`。完整参数以 CLI 帮助为准：

```bash
./run_single_training.sh --help
./run_single_training.sh evolve --help
./run_single_training.sh native-test --help
```

## 支持的单数据集

`gaia`、`locobench_fi`、`locobench_cr`、`loca`、`beyondswe_depmigrate`、`beyondswe_crossrepo`。

外部数据通过 `SKILL_MAS_GAIA_ROOT`、`SKILL_MAS_LOCOBENCH_ROOT`、`SKILL_MAS_LOCA_ROOT`、`SKILL_MAS_BEYONDSWE_ROOT` 配置，也可以按 CLI 帮助传入 JSONL 文件。

## 关键运行约定

- `k-trajectories=1` 只运行一条基线轨迹，不会触发需要轨迹对比的反思；要进行官方的多轨迹对比反思，使用 `k-trajectories >= 2`。
- 训练状态和轨迹会写入结果目录，可使用同一个 `run-id` 恢复。
- native 任务的有效执行预算与 API 恢复等待分开计算。API 恢复有独立的 800 秒墙钟窗口，不计入有效执行时间。
- 超时任务的轨迹会保留，方便判断是任务执行超时还是模型/API 等待。
- 结果、日志、缓存和外部数据不会提交到 Git。

## 发布检查

提交前确认没有 `.env`、benchmark 原始数据、API key、个人绝对路径或实验结果；并运行 `python3 -m compileall` 与 CLI `--help` 检查。
